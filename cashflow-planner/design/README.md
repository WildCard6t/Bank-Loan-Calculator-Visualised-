# Approved design references

Source files from the design canvas. They are design-format files (`.dc.html`), not pages the site serves, and they are not linked from any page.

| File | What it is |
| --- | --- |
| `cash-flow-board.dc.html` | The approved **Cash-flow board**: heading "Pin pieces where you like", a Next payday card, a Wish list panel with "Plan for: Cheapest route / Emergency", reservoirs Rent, Bills, Safety buffer, Car and Holiday, and an "Add a reservoir" slot. Dark, glowing colours by default; the `dark` tweak switches to the light paper version. |
| `cash-flow-sankey.dc.html` | The Sankey view of the same payday (money in, spare cash, priority, pots). Kept as a second view. |

All figures are sample values. The live `cashflow.html` has the board look (pinned, glowing reservoirs hanging from a supply pipe) but not yet the Wish list panel, the Plan-for switch or the Add-a-reservoir slot.
